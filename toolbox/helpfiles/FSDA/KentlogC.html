KentlogC

KentlogC computes the log of the Kent distribution normalizing constant log c(kappa,beta

expand all in page

Syntax

  • logc=KentlogC(kappa, beta)example
  • logc=KentlogC(kappa, beta, mterms)example

Description

KentlogC evaluates, in log-space, the normalizing constant of the Kent (Fisher-Bingham FB5) distribution on S^2 (the unit sphere in R^3):

c(kappa,beta) = 2*pi * sum_{j=0}^{inf} Gamma(j+1/2)/Gamma(j+1) * beta^(2j) * (kappa/2)^(-2j-1/2) * I_{2j+1/2}(kappa) as given in Kent (1982, eq. 3) and Mardia et al. (2021, eq. 5), where I_nu is the modified Bessel function of the first kind. Each term is evaluated in log-space using the exponentially scaled Bessel function besseli(nu,kappa,1), so that no overflow occurs for large kappa, and the terms are added with the log-sum-exp device.

Special cases:

beta=0: the Kent density reduces to the vMF density with parameter kappa, and log c(kappa,0) = log(4*pi) + log(sinh(kappa)) - log(kappa) = -vMFlogC(kappa,3).

kappa=0: (with beta=0) uniform distribution on S^2, c = 4*pi.

NOTE: the Kent distribution is defined ONLY on S^2 (p=3). This function does not generalise to higher-dimensional spheres (unlike the vMF functions in this toolbox).

  • Compare KentlogC with the analytic vMF special case (beta=0).

    • . For beta=0, log c(kappa,0) = log(4*pi) + log(sinh(kappa)) - log(kappa). 

    kappa = [1 5 20 100];
beta  = zeros(size(kappa));
logc_kent = arrayfun(@(k,b) KentlogC(k,b), kappa, beta);
logc_vMF  = log(4*pi) + log(sinh(kappa)) - log(kappa);
fprintf('kappa=%6.1f: Kent series=%.6f, vMF analytic=%.6f, diff=%.2e\n', ...
[kappa; logc_kent; logc_vMF; abs(logc_kent-logc_vMF)]);

  • Compare KentlogC with numerical integration of the Kent kernel.

    • . In the canonical frame, with t=cos(colatitude) and longitude phi, c(kappa,beta) = int_0^{2pi} int_{-1}^{1} exp(kappa*t + beta*(1-t^2)*cos(2*phi)) dt dphi. 

    % The factor exp(-kappa) is taken out to avoid overflow.
kb = [5 2; 20 9; 30 10; 100 45];
for i = 1:size(kb,1)
kappa = kb(i,1); beta = kb(i,2);
f = @(t,phi) exp(kappa*(t-1) + beta*(1-t.^2).*cos(2*phi));
logc_num = log(integral2(f,-1,1,0,2*pi,'AbsTol',1e-13,'RelTol',1e-11)) + kappa;
fprintf('kappa=%5.1f beta=%5.1f: series=%.6f, integral=%.6f\n', ...
kappa, beta, KentlogC(kappa,beta), logc_num);
end

    Input Arguments

    expand all

    kappa — Concentration parameter. Scalar >= 0.

    Data Types: single| double

    beta — Ovalness parameter. Scalar >= 0.

    The Kent density is unimodal for 0 <= beta < kappa/2. beta=0 gives the isotropic (vMF) special case.

    Data Types: single| double

    Optional Arguments

    mterms — Number of terms of the series. Scalar positive integer or empty.

    If it is empty or missing (default) the number of terms is chosen automatically: terms are added until they become negligible with respect to the partial sum. If mterms is given, exactly mterms terms (j=0,...,mterms-1) are used; note that a fixed small number of terms (e.g.

    the value 20 suggested by Mardia et al., 2021) is not enough when kappa is large and beta is close to kappa/2.

    Example: 30

    Data Types: double

    Output Arguments

    expand all

    logc —log c(kappa,beta). Scalar

    The Kent log-density is -logc + kappa*(gamma3'*x) + beta*[(gamma1'*x)^2-(gamma2'*x)^2].

    Additional Details

    CONVERGENCE OF THE SERIES The ratio between two consecutive terms is t_j/t_{j-1} = (2j-1)/(2j) * (2*beta/kappa)^2 * I_{2j+1/2}(kappa)/I_{2j-3/2}(kappa) (the order of the Bessel function increases by 2 from one term to the next). All factors are smaller than 1 when beta<kappa/2, so the terms decrease monotonically, but the decrease is slow when 2*beta/kappa is close to 1 and kappa is large: for this reason the default is an adaptive number of terms. The automatic rule stops when the last term is smaller than eps*(1-(2*beta/kappa)^2) times the partial sum (the second factor bounds the geometric tail), or after 5000 terms.

    VERY LARGE KAPPA For kappa>1e8 the Bessel functions cannot be computed accurately and the high-concentration approximation of Kent (1982) c(kappa,beta) ~ 2*pi*exp(kappa)/sqrt((kappa-2*beta)*(kappa+2*beta)) is returned.
