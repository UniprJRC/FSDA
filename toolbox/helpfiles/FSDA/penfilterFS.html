penfilterFS

penfilterFS fits a generic quadratic penalized trend on a selected subse

expand all in page

Syntax

  • out=penfilterFS(y,K,N)example
  • out=penfilterFS(y,K,N,Name,Value)example
  • [out,Aready]=penfilterFS(___)example

Description

penfilterFS is a low-level fitting routine for quadratic smoothers in the observation space. Given a symmetric positive semidefinite penalty matrix K, it solves min_{m,beta} ||S(y-m-X*beta)||^2 + lambda*m'*K*m + beta'*betaPenalty*beta, where S selects the observations in bsb. If X is empty, the criterion reduces to min_m ||S(y-m)||^2 + lambda*m'*K*m.

Let N be a matrix whose columns span null(K), and let B0 span the null space of betaPenalty. Conditional identification on bsb requires rank([N(bsb,:) X(bsb,:)*B0]) = size(N,2)+size(B0,2).

The matrix N is therefore a first-class input of the routine. This avoids recomputing a numerical null space in repeated robust-fitting calls and makes the elemental-subset dimension explicit. If K is positive definite, use N=zeros(T,0) or N=[].

penfilterFS intentionally performs fitting only. Variance estimation and prediction intervals depend on the stochastic interpretation attached to a particular penalty and are left to wrappers such as hpfilterFS.

example

out =penfilterFS(y, K, N) HP penalty: check equivalence with hpfilterFS in fitting-only mode.

example

out =penfilterFS(y, K, N, Name, Value) Third-difference penalty.

example

[out, Aready] =penfilterFS(___) Positive definite penalty.

Examples

expand all

  • HP penalty: check equivalence with hpfilterFS in fitting-only mode.

    • . 

    rng(1000)
T=120;
t=(1:T)';
e=ones(T,1);
D2=spdiags([e -2*e e],0:2,T-2,T);
K=D2'*D2;
N=[ones(T,1) t];
X=[sin(2*pi*t/12) cos(2*pi*t/12)];
y=0.02*t+X*[3;-2]+randn(T,1);
bsb=(1:100)';
outPen=penfilterFS(y,K,N,'bsb',bsb,'X',X,'lambda',1600);
outHP=hpfilterFS(y,'bsb',bsb,'X',X,'lambda',1600,...
'fitonly',true);
assert(max(abs(outPen.mhat-outHP.mhat))<1e-9)
assert(max(abs(outPen.yhat-outHP.yhat))<1e-9)
assert(abs(outPen.objective-outHP.objective)<1e-7)

  • Third-difference penalty.

    • . The null space is formed by polynomials of degree at most two. 

    rng(12345)
T=100;
t=(1:T)';
e=ones(T,1);
D3=spdiags([e -3*e 3*e -e],0:3,T-3,T);
K3=D3'*D3;
x=(t-mean(t))/T;
N3=[ones(T,1) x x.^2];
y=2+0.03*t+4*sin(2*pi*t/T)+randn(T,1);
out=penfilterFS(y,K3,N3,'lambda',1e5,'plots',true);

    • . 

    rng(123)
T=80;
K=speye(T);
N=zeros(T,0);
y=randn(T,1);
out=penfilterFS(y,K,N,'lambda',2);

    Input Arguments

    expand all

    y — Time series to analyze. Vector or timetable.

    Vector with T elements containing the response. Missing values are allowed outside bsb. If y is a timetable, the first variable is used and row times are used in plots.

    Data Types: double | timetable

    K — Quadratic penalty matrix. T-by-T symmetric positive semidefinite matrix.

    The penalty contribution is lambda*m'*K*m. K can be dense or sparse.

    For the Hodrick--Prescott penalty K=D2'*D2, where D2 is the second-difference matrix.

    Data Types: double | sparse double

    N — Basis of null(K). T-by-r matrix, where r is the nullity of K.

    The columns of N must span the complete null space of K.

    The basis need not be orthonormal; penfilterFS internally orthonormalizes it. If K is positive definite, use [] or a T-by-0 matrix.

    Data Types: double

    Name-Value Pair Arguments

    Specify optional comma-separated pairs of Name,Value arguments. Name is the argument name and Value is the corresponding value. Name must appear inside single quotes (' '). You can specify several name and value pair arguments in any order as Name1,Value1,...,NameN,ValueN.

    Example: 'bsb',(1:80)' , 'X',[sin(2*pi*t/12) cos(2*pi*t/12)] , 'betaPenalty',Pseason , 'betaPenaltyNullBasis',Nseason , 'lambda',1600 , 'nocheck',true , 'plots',true

    bsb —Indices of observations used in the fit.vector.

    If bsb is empty (default), all finite observations in y are used. All y(bsb) values must be finite. The minimum number of selected observations is size(N,2) plus the nullity of betaPenalty, except when this number is zero, in which case at least one observation is required.

    Example: 'bsb',(1:80)'

    Data Types: double

    X —Additional linear components.matrix | empty.

    T-by-q matrix entering the fitted signal as m+X*beta.

    Directions penalized by betaPenalty need not be identified by the data. The unpenalized directions must be identified jointly with null(K). The default is empty.

    Example: 'X',[sin(2*pi*t/12) cos(2*pi*t/12)]

    Data Types: double | empty

    betaPenalty —q-by-q positive-semidefinite matrix P_beta applied to beta.its scale is included in the matrix.

    The contribution to the objective is beta'*P_beta*beta. If empty (default), beta is unpenalized.

    Example: 'betaPenalty',Pseason

    Data Types: double or sparse double

    betaPenaltyNullBasis —Optional basis for the full null space of betaPenalty.these coefficient directions must be identified by the data.

    If omitted, penfilterFS computes the basis. Supplying a precomputed basis avoids repeated null-space decompositions in repeated fitting calls.

    Example: 'betaPenaltyNullBasis',Nseason

    Data Types: double

    lambda —Smoothing parameter.positive scalar.

    The criterion is RSS + lambda*m'*K*m + beta'*betaPenalty*beta. The default value is 1. No automatic frequency scaling is used because the scale of a generic K is user-defined.

    Example: 'lambda',1600

    Data Types: double

    nocheck —Skip structural checks on K and N.boolean.

    If nocheck=false (default), penfilterFS checks symmetry and approximate positive semidefiniteness of K, full column rank of N, and verifies that K*N is numerically zero.

    Set nocheck=true only after K and N have been validated, for example inside repeated LTSts concentration steps.

    Identification on the selected subset is always checked.

    Example: 'nocheck',true

    Data Types: logical

    plots —Plot observed values and fitted components.boolean.

    If plots=true, the observed series and penalized trend are shown. When X is nonempty, the complete fitted signal is also shown. The default is false.

    Example: 'plots',true

    Data Types: logical

    Additional Details

    The matrix A = W + lambda*K, W=S'*S, is common to both the trend-only and joint trend-regression problems.

    If X is present, m is profiled out exactly. With Xb=X(bsb,:), P = W-W*A^{-1}*W, and beta solves (X'*P*X+betaPenalty)*beta = X'*P*y.

    The implementation never forms P explicitly. This is the same profiling algebra used in hpfilterFS, but with the HP matrix D2'*D2 replaced by a generic fixed positive semidefinite K.

    The supplied N must span the complete null space of K. penfilterFS checks that the supplied columns lie in null(K), but it does not compute the nullity of a large sparse K in order to verify completeness. Supplying an incomplete N can therefore lead to a singular A for some subsets; this is detected when the penalized system is factorized.
